Формат ответа. Последней строкой выведи ровно одну строку вида:
FINAL_ANSWER: {"answers": [{"name": "<имя>", "value": <число>, "unit": "<единица>"}]}

Правила:
- name — точно как в списке искомых величин выше; по одному элементу на каждую величину;
- value — число в основных единицах СИ без приставок (Н, Н·м, Па, Дж, Вт, А, В, Ом, К, м³/с), десятичная точка, допускается запись 1.5e3;
- unit — обозначение единицы латиницей: "N", "N*m", "Pa", "J", "W", "A", "V", "Ohm", "K", "m^3/s".
